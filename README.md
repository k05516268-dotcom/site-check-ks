# site-check-ks

Скил (навык) для ИИ-ассистента Kimi. Проверяет сайт перед сдачей заказчику: контент, UX, дизайн, конверсия, технические мелочи и юридические требования РФ. Работает на 4 ширинах экрана со скриншотами. Скил ничего не правит - только находит и докладывает.

## Когда срабатывает

1. Просят проверить сайт или сделать аудит перед запуском или сдачей.
2. Просят разбор аналога (чужого сайта).
3. Просят сравнение своего сайта с конкурентом.

## Как работает

1. Получает ссылку на сайт (или путь к локальному проекту).
2. Открывает сайт на ширинах 375, 768, 1280 и 1920 и сохраняет скриншот каждой.
3. Проходит по всем страницам и по чек-листу категорий: контент, UX и структура, конверсия, дизайн, технические мелочи, юридические требования (для коммерческих сайтов РФ).
4. Собирает отчёт файлом: каждая находка - где, в чём проблема, как исправить, с меткой важности (срочно / стоит сделать / мелочь).
5. В чате даёт короткое резюме топ-3 находок, полный отчёт прикладывает файлом.

## Режим «разбор аналога»

Проверяет чужой сайт по тем же категориям и выдаёт таблицу сравнения «мой сайт / аналог», плюс 3 идеи, которые стоит перенять, и 3 ошибки аналога, которых надо избегать.

## Железные правила

- Скил ничего не правит вообще. Правки - отдельная задача после явного согласия пользователя.
- Не выдумывает находки: каждую подтверждает скриншотом или цитатой.
- По юридическим вопросам не цитирует нормы по памяти, каждая находка завершается пометкой «сверить с юристом».

## Пример

Запрос: «Проверь мой лендинг перед сдачей». Скил откроет сайт на четырёх ширинах, пройдёт чек-лист, найдёт, например, форму без чекбокса согласия и кнопку с неясным текстом, и выдаст отчёт «отчёт-проверка-ГГГГ-ММ-ДД.md» со скриншотами и приоритетами.

## Установка в Kimi

1. Откройте создание скила командой /skill-creator.
2. Вставьте текст из файла SKILL.md.
3. Сохраните скил и проверьте тестовой проверкой любого сайта.
